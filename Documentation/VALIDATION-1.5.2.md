# 1.5.2 验证记录

日期：2026-10-01。目标：macOS 26+、Apple Silicon。

## 实际任务的模型响应

用户通过 1.5.1 修复后的采集入口重新打开官方桌面客户端，正常任务流量经过本机 HTTPS 代理，取得两个并行任务分别上报的 `gpt-6.1-sol` 与 `gpt-6-luna`。响应使用明确的任务及轮次 ID 分别关联；本次验证没有额外发起模型生成测试。原始 Codex 配置、认证、系统代理、钥匙串与系统信任没有修改。代理只保存白名单模型元数据，不保存原始抓包、提示或回复正文。

1.5.2 将本机网络响应与手动导入分开记录来源，新采集写入私有 `NetworkEvidence/`。旧版本保留的 `network-models-<UUID>.jsonl` 能恢复来源标记；历史合并补齐来源而不复制记录。手动导入文件中的来源字段不能自行宣称来自网络采集。

明确边界：这些结果是服务端对各自响应上报的模型名，无法证明未公开的模型权重。来源标签不是密码学签名；有权限修改本地文件的进程能改动元数据。旧连接、丢失响应、远程设备与缺少明确关联的记录不能因此恢复。实机正在使用的采集入口属于 1.5.1，新版来源与展示使用测试、最终构建和隔离演示验证；没有为升级而中断正在工作的客户端。

## 界面

- 原生浅色与深色截图检查两个长中文任务标题：选中和未选中行都显示两行标题、模型与状态，不再压缩裁切。
- 网络响应使用“网络响应采集”标签，手动导入使用“手动导入”，有效响应不再误标“导入 · 未认证”。空请求 / 安全缓冲区域隐藏。
- 主界面、空详情与关于窗口共用应用图标。菜单栏使用相同机器人与放大镜图案的单色模板，跟随系统菜单栏深浅外观。
- 按最终用户要求，菜单弹窗顶部仅保留“用量 / 番茄钟”切换，移除 Logo 与软件名；统一刷新位于用量页面右下角、更多功能展开按钮左侧。
- 双任务菜单按内容高度收缩；独立番茄钟紧凑显示并使用秒级截止时间。网站 / README 截图更新为明确标注的演示数据，不包含实际账户或任务。
- Antigravity 未提供 Token 总数时隐藏该行。WorkBuddy / OpenCode Go 不显示不可用服务状态；无数据的额度字段与重置卡不显示空占位，真实零值仍保留。

## 公开服务状态

OpenAI 汇总全部可见公开组件，不再限于 Codex 分组；RSS 保留全部产品的最近事件。状态文本和多行事件左对齐。DeepSeek 使用官方 RSS，不将没有事件推断为每台服务器的实时健康保证。

Google 的实机匿名查询成功取得 Gemini API / AI Studio 与 Google Cloud 两个来源。Gemini 使用官方状态网页同款 `ListIncidentsHistory` 空请求，动态取得公开网页客户端标识，未使用用户登录、Cookie 或个人 API Key；覆盖全部事件与流量层级。Google Cloud 使用官方 incidents JSON 与 Atom。各来源单独展示，不声称 Google Cloud 是 Antigravity 专属组件。该 Google 网页内部接口可能随网页版本变化；失败来源隐藏，不冒充正常状态。

公开来源：[OpenAI](https://status.openai.com/)、[Gemini API / AI Studio](https://aistudio.google.com/status)、[Google Cloud](https://status.cloud.google.com/)、[DeepSeek RSS](https://status.deepseek.com/feed.rss)。

## 自动检查与发行包

最终代码通过 95 个 Swift 测试（10 个套件）和 7 个采集插件测试。新增覆盖采集 / 导入来源隔离、旧来源迁移去重、可用状态平台范围、Google Cloud 全部服务、Gemini 多阶段事件时间顺序与未知 / 布尔阶段拒绝。已有检查覆盖跨任务及轮次隔离、缓冲大小、SSE 分片、历史损坏、Token 溢出、时间解析与计时恢复。

最终 Release 构建成功，二进制为 arm64；严格 ad-hoc 签名验证通过。发行 ZIP 仅包含应用，不包括用户数据、认证、证书密钥、调研脚本、私有日志与构建缓存。当前仍未进行 Apple Developer ID 签名或公证，不能将本次签名检查描述为已公证。

本轮没有重测所有平台的真实登录流程；没有有效凭据的平台仍依赖离线协议检查。界面演示不能代替服务端协议长期稳定性保证，测试也不能证明不存在任何漏洞。完整隐私边界见 [SECURITY.md](../SECURITY.md)，既往 TLS 修复记录见 [1.5.1](VALIDATION-1.5.1.md)。
