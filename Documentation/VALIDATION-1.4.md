# 1.4.0 验证记录

日期：2026-10-01。目标：macOS 26+、Apple Silicon。Swift 6.2 / macOS 26 SDK，在当前 Mac 上编译与验证。

## 已验证

- 83 个离线测试、8 个测试套件全部通过。新增覆盖 canonical 和 legacy 桌面历史、完整路由 item 的实时 patch、任务关联、协议版本、修订号缺口、所有者变化、工具输出伪装、核心模型日志，以及实时历史合并的删除标记 / 运行状态保持。
- arm64 Release 构建成功；ad-hoc 签名严格校验通过。应用仍为 LSUIElement，默认菜单栏运行。
- 只读连接当前 Codex / ChatGPT 的本机 IPC，握手、订阅与状态更新成功。原型和最终 Swift 监听器都读取到两个现有任务的快照。加入对端 UID 和 OpenAI 进程签名检查后仍成功。
- 最后一次 Swift CLI 检查：238 个任务、1,125 个轮次，2 个实时状态快照；0 条路由观察、0 条任务服务端模型证据；扫描诊断为 0。数量是检测时快照，不是固定账户或测试夹具。
- 监听器由 DispatchSource socket 可读事件驱动，正常连接没有周期轮询；不变化的状态不投递 UI。连接失败从 2 秒退避到最多 60 秒。最多订阅 40 个已知任务，取消订阅释放关联索引，单帧限制 16 MiB。
- 确认官方源码的 ServerModel 来自模型响应头；客户端一致模型使用 info 日志，模型差异使用 warn 并发出明确路由事件。不能把没有切换事件当作模型一致的证据。
- 新的本机设置字段采用可选解码，旧设置中的数据源路径和选项不会因新字段缺失而丢失。实时证据不替换标题，不改变其他任务状态，不恢复已移除任务。

- 官方已登录账户只读查询成功：可用重置卡数量与购买额度余额分别取得。未消耗重置卡，不保存兑换 ID，临时认证副本结束后清理。
- 新增重置卡空值 / 零值 / 汇总数量 / 到期与隐私、旧档解码、跨产品状态隔离、未知状态和 Google Cloud 覆盖边界测试。费用估算代码已移除。

- 原生菜单截图已检查：五个平台统一单色、系统蓝色选中，购买余额与重置卡字号层级相同，顶部一个按钮统一刷新；独立核验结果不在 Codex 用量菜单中。
- Website 使用 WebKit 实际渲染浅 / 深色与 390 px 手机布局；图片全部加载，主题按钮与截图切换通过，修复装饰溢出后无横向滚动。Pages 新图标和主题网站部署成功。
- Codex 原生分组状态接口实测返回可识别状态；DeepSeek 当前本机网络请求失败，未宣称正常。Google Cloud 的覆盖限制保持明确。

## 尚未验证 / 明确限制

- 没有关闭正在执行本任务的 Codex / ChatGPT，因此未进行客户端重开后的端到端模型日志验证。默认 info 模式和实验性 SSE / WebSocket trace 启动入口已实现，但不能据此宣称当前任务实际模型已被确认。
- 本轮未新增模型推理请求。先前获准的独立 pong 核验结果不代表当前任务。
- IPC 是桌面内部协议，按当前观察到的版本 11 解析；后续客户端升级可能需要适配。远程 / 云端 / 其他设备任务不在这个本机接口范围内。
- 历史只恢复当前桌面缓存或原始日志中仍存在的明确模型事件；没有字段或明确轮次 ID 时不关联。快照证据时间是本机检测时间，不是伪造的原始服务端 UTC 时间。
- 详细 trace 默认关闭，Codex 自身可能因此保存任务输入输出，并增加开销；Model Lens 仅保存白名单模型元数据。结束后正常重新打开客户端即可恢复默认日志级别。
- 服务端报告名称是客户端可观察的最强识别信息之一，不是对服务端模型权重的独立证明。
