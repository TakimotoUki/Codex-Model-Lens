验证日期：2026-09-30 / 2026-10-01。目标为 macOS 26+ Apple Silicon，实际本机系统为 macOS 27、arm64、Swift 6.4。离线测试、构建脚本和 CI 公开，可以复核；有限测试不能证明没有任何漏洞。

公开仓库的 [首次完整 CI](https://github.com/TakimotoUki/Codex-Model-Lens/actions/runs/36758842175) 在全新的 `macos-26-arm64` 运行器、Swift 6.3.3、SDK 26.5 上完成 59 项测试、arm64 release 构建和签名完整性检查。GUI 截图仍是本机 macOS 27 的验证。

## 自动化与审核

- 59 项测试、5 个 suite 全部通过。覆盖模型 / 响应关联、消息伪装排除、安全缓冲边界、预热排除、冲突与缺失输出、只读 SQL、历史保留、增量与文件替换、Token 溢出与单位、平台字段解析、账目去重、计时暂停和恢复。
- 通读全部源码和发布脚本，修复发现的账户缓存混用、缺失额度被当作零、重复费用、Token 溢出、CLI 取消与超时、临时文件权限、CSV 公式注入、无关消息误识别、popover / 空列表 / 工具窗口布局问题。
- 发布包仅包含 arm64 App、图标和 Info.plist，不包含凭据、用户任务历史、研究记录或 QA 数据。核对最低系统 26.0、LSUIElement、签名完整性与 ZIP 内容。
- 当前产物为 ad-hoc 签名，没有 Developer ID 公证。不能将本机运行成功等同于所有新 Mac 无提示安装；安装说明提供系统允许打开流程。

## 性能

用本机数百任务和大型日志、隔离数据目录运行；两个测试实例同时运行。以 `sample` physical footprint 计量，不将可回收的虚拟 / RSS 页面等同于实际物理占用。

| 测量 | 普通菜单栏后台 | 番茄钟运行后台 |
| --- | --- | --- |
| 稳定阶段 physical footprint | 57.0 MB | 126.6 MB |
| 含首次完整扫描的峰值 | 197.1 MB | 355.8 MB |
| 35 秒 CPU time 增量 | 0.13 秒 | 0.72 秒 |
| 单核百分比换算 | 约 0.37% | 约 2.06% |

这是上述条件的测量，不是所有设备 / 日志规模的上限。首次扫描未索引历史，后续增量读取。每秒计时不写文件，后台扫描降低频率。安装包大小和 SHA-256 见 Release 附件。
