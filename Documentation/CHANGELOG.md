# 更新记录

## 1.4.0 · 2026-10-01

- 新增只读桌面 IPC 观察，读取 canonical / legacy 轮次中的明确模型路由事件；支持实时 patches，修订号缺口重新请求快照，协议变化不猜测解析。
- 连接检查 Unix socket 所有者、目录权限、对端 UID 与 OpenAI 进程签名；数据仅保存任务 / 轮次与模型白名单字段。
- 新增官方核心 ServerModel 日志解析，覆盖服务端模型与所选模型一致的记录。
- 设置增加按次启动的模型采集入口，以及默认关闭的实验性响应字段详细日志；不会自动关闭现有 Codex / ChatGPT。
- 实时证据合并保持其他任务的状态、已删记录和已有标题。关闭监测时断开，连接无轮询，失败重连逐步退避到 60 秒。
- 本机读取现有任务状态成功，当次路由证据为 0；重开后的日志采集需继续验证，未宣称能恢复任何缺失历史或验证服务端权重。


## 1.3.1 · 2026-10-01

- 修复 Application Support 已存在时跳过旧数据的迁移，恢复缺失的独立核验、设置和历史证据；合并去重，保留损坏文件、已有设置与删除标记。
- 接收先于响应 ID 的 WebSocket 模型响应头；同一响应优先采用模型响应头，保留普通字段，其他响应仍分别判断。
- 独立核验按有输出的响应判定，忽略无关 metadata 时不丢失模型响应头；避免继承 `LOG_FORMAT=json` 改变核验日志格式。
- 菜单显示最近独立核验，主窗口增加已确认核验入口；任务缺失字段时说明“本轮未记录服务端模型”。
- 旧目录恢复在后台执行，成功后保存完成标记，避免 Finder 启动时重复读取受保护的桌面旧文件而卡住主线程。
- 69 项离线测试覆盖数据恢复、迁移幂等、响应头优先级与跨响应隔离；构建脚本按 Info.plist 版本打包。

## 1.3.0 · 2026-10-01

- 默认菜单栏运行，无 Dock 与初始主窗口；用量和番茄钟独立切换，工具窗口独立打开。
- 紧凑 Liquid Glass / 系统蓝色界面；修复番茄钟空白、检测范围布局、空列表顶部偏移、工具窗口关闭和预览捕获。
- 自定义专注 / 休息、暂停恢复、系统提醒和秒级菜单栏倒计时；popover 根据内容大小和图标位置跟随。
- 可单独启停 Codex、Antigravity、OpenCode Go、DeepSeek、WorkBuddy；新增 Keychain 多账户、Cost、Usage Dashboard、Status Page 与 About。
- 接入 Codex 官方账户 / 额度 / Token 元数据、Antigravity 本机服务器、DeepSeek 余额、OpenCode Go Usage API / 手动工作区 Cookie / SQLite 费用、WorkBuddy 支持认证格式的额度 API 和本机积分后备。
- 扩展模型响应头 / response.metadata 检测及独立手动核验；明确区分预热、安全缓冲、请求模型和服务端报告，缺失或冲突保持未确认。
- 修复账户缓存边界、Token 溢出、费用重复统计、未知额度默认值、私有文件权限、CSV 公式前缀、子进程超时和取消；流式增量读取降低首次扫描内存压力。
- 数据迁移到用户 Application Support；发布 arm64 安装包、完整支持 / 隐私文档、测试 CI 和 GitHub Pages 网站。新版 WorkBuddy 加密认证余额、Antigravity Token 总数仍不支持，缺失数据不推算。

## 1.2.0 · 2026-09-30

- 新增官方 CLI 元数据读取和用户明确启动的隔离模型核验。

## 1.1.0 · 2026-09-30

- 修复中间栏在空列表时标题、统计卡片与搜索框向下偏移；空状态和任务列表使用同一可伸展内容区域。
- 采集 Responses HTTP 通信记录，保留 UTC 时间、任务／轮次关联、请求 ID、HTTP 状态及相关响应头。
- 新增安全缓冲任务视图、轮次缓冲提示及可重试模型展示。安全缓冲信息不作为实际交付模型。
- 新增请求诊断：搜索、UTC 日期筛选、缓冲／错误筛选，按请求、模型、日期或任务查看，复制证据与导出 JSON／CSV。
- 统计区分日志条数、按请求 ID 去重的请求数和无法确定请求 ID 的记录；排除聊天和工具引用。
- 历史升级到 schema 2，保留 schema 1 原有任务及模型证据，并持久保存通信证据和日志覆盖范围。
- 支持结构化安全缓冲事件的读取及脱敏导入，扩展模型 CSV 中对应字段。
- 命令行增加请求统计和 `--requests-csv` 导出。
- 可右键移除本地任务及关联请求证据，持久保存跳过 ID，防止后续扫描重新添加；按要求移除 8 月 17 日的两条旧审校记录。
- 请求列表使用只为现有记录绘制的整行选择界面，保持空白区域简洁；补充主窗口显示保障。
