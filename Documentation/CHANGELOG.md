# 更新记录

## 1.5.2 · 2026-10-01

- 包含 1.5.1 的采集 TLS 登录修复与启动前账户检查；官方桌面客户端已取得两个并行任务各自的服务端模型响应，按任务及轮次关联。
- 修复中栏长标题选中时行高压缩、标题和模型被裁切的问题，为原生列表提供明确最小高度与完整内容测量。
- 本机网络响应采集与手动导入使用独立来源标记，新采集使用私有 NetworkEvidence 目录；旧记录恢复来源且不重复。已采集响应不再显示“导入 · 未认证”。
- 统一主界面和关于窗口的应用图标；菜单栏改用相同机器人 / 放大镜图案的原生单色线条模板，深浅外观自动适配。菜单弹窗顶部只保留功能切换，移除软件名和 Logo；统一刷新位于右下角、更多功能按钮左侧。
- 服务状态左对齐并扩展到 OpenAI 全部公开组件和事件；Google 聚合 Gemini API / AI Studio 全流量层级与 Google Cloud 公开事件。Google 查询无需用户登录或个人 API Key。
- 隐藏 OpenCode Go / WorkBuddy 的不可用状态区域、未返回的 Token 或重置卡，以及空请求证据区域。可用功能和实际读取错误仍有清楚提示。
- 95 个 Swift 测试及 7 个代理插件测试通过；验证边界见 VALIDATION-1.5.2.md。

## 1.5.1 · 2026-10-01

- 修复采集模式导致 Codex 无法加载账户/配置的 TLS 错误：独立根 CA 签发服务端证书，服务端证书使用 CA:FALSE、serverAuth 与正确的本机 SAN，解决 rustls 的 CaUsedAsEndEntity 拒绝。
- 新增启动前官方 Codex CLI 账户只读检查，实际使用 rustls 和代理连接核验；失败则停止本次代理并保留正常启动路径，不再用普通 HTTPS 测试代替客户端验证。没有额外模型生成请求。
- 多任务菜单按实际内容高度收缩，移除固定“任务数 × 行高”的预留；两任务未确认行、八任务滚动上限已做原生截图检查。
- 复用有锁保护的 ISO 时间解析器，桌面通信按帧释放临时 Foundation 对象和空接收缓冲，降低历史读取与监听时的重复分配。
- 90 个 Swift 测试、7 个代理插件测试通过，新增并发时间解析与非有限时间戳检查。采集验证边界见 VALIDATION-1.5.1.md。

## 1.5.0 · 2026-10-01

- 新增按需下载的网络响应采集：本机 HTTPS 反向代理读取入站 WebSocket / SSE 的服务端模型字段，并按明确任务 / 轮次 ID 保存；不会将客户端请求模型当作服务端报告，也不继承上一轮模型。
- 仅对手动重新启动的官方客户端传入后端地址和进程内 CA；不修改原始配置、认证、客户端 bundle、系统代理或证书信任。采集默认关闭，必须先自行退出客户端，不能追溯已丢失的响应。
- 组件固定官方版本与 SHA-256，私有副本重建 ad-hoc 签名；不写原始抓包、提示、回答或认证头。限制元数据缓存和记录数量，所属主程序退出后代理自动停止。
- 真实抓包样本提取到明确关联的服务端 gpt-6.1-sol，匿名预热被排除；本机 TLS 代理启动和证书路径已验证。当前桌面客户端未被重启，本轮没有额外推理请求，重新启动后桌面完整链路尚需使用验证。
- Antigravity 无需打开主 App，即可用签名官方语言服务器进行短期后台查询；认证只复制到 0700 / 0600 临时目录，退出后清理，不改原始登录。有效重置时间下的已验证 proto3 零值正确显示 0%；新版可选字段仍保留未知。当前 Gemini 0%、Claude / GPT 约 0.11% 已由后台原生查询验证。
- Codex 与 DeepSeek 使用官方 RSS 展示最近事件，Antigravity 展示 Google Cloud Atom 参考；Google 订阅未覆盖 Antigravity 的边界保持明确。限制 XML 大小、禁用实体和非官方链接。
- 重置卡前移除刷新形图标，余额与重置卡保持同层级，页面只有顶部统一刷新按钮。
- 89 个 Swift 测试和 7 个代理插件测试通过；arm64 Release 构建与签名校验通过。验证与安全边界见 VALIDATION-1.5.md 和 SECURITY.md。

## 1.4.0 · 2026-10-01

- 采用用户提供的任务观察图标，加深石墨底色、圆角外透明；五个平台官方标志统一为单色模板。
- 唯一刷新按钮更新所有已启用平台和任务；余额与重置卡使用同一字号层级。
- 介绍网站重设计，支持手动黑白切换、系统跟随、移动布局及完整功能说明。
- 移除 Cost 入口与估算代码；用量概览、添加账户与关于采用中文标签，独立核验结果移出 Codex 用量菜单。
- Codex 重置卡单独读取官方汇总数量和到期时间，与购买额度余额分开显示；本机只读验证可用卡数量，与购买余额独立。
- 官方服务状态放在各平台 Token 下方，按需读取、5 分钟缓存，未覆盖的平台和未知组件不误判正常。

- 新增只读桌面 IPC 观察，读取 canonical / legacy 轮次中的明确模型路由事件；支持实时 patches，修订号缺口重新请求快照，协议变化不猜测解析。
- 连接检查 Unix socket 所有者、目录权限、对端 UID 与 OpenAI 进程签名；数据仅保存任务 / 轮次与模型白名单字段。
- 新增官方核心 ServerModel 日志解析，覆盖服务端模型与所选模型一致的记录。
- 设置增加按次启动的模型采集入口，以及默认关闭的实验性响应字段详细日志；不会自动关闭现有 Codex / ChatGPT。
- 实时证据合并保持其他任务的状态、已删记录和已有标题。关闭监测时断开，连接无轮询，失败重连逐步退避到 60 秒。
- 本机读取现有任务状态成功，当次路由证据为 0；重开后的日志采集需继续验证，未宣称能恢复任何缺失历史或验证服务端权重。
