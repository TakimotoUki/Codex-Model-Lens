# 设计与检测约定

## 1.3.0 菜单栏与用量架构

App 使用 `LSUIElement`、accessory 激活策略和受抑制的初始窗口。菜单首次点击才建立，只有用户操作才打开任务工作区；工具窗口独立。番茄钟与用量使用独立状态，系统蓝色和原生 Liquid Glass 操作层，popover 按内容测量大小并随 status item 锚点缓动。

扫描使用数据库游标、文件偏移和替换识别。JSONL 使用可复用流式缓冲并跳过无关消息；每行释放临时对象。主界面可见时使用设定间隔，后台且 Codex 打开时至少 15 秒，关闭时 60 秒。网络额度仅读取启用并选中的平台，成功结果缓存 5 分钟。没有自动生成模型回复的检测。

手动账户凭据在 Keychain，文件只保存账户 UUID、标签和类型。Codex 本机账户使用身份摘要隔离缓存，读取前后检查登录身份；删除账户清理对应快照与历史。HTTP 使用 ephemeral session、拒绝重定向和有限响应大小。Antigravity 本机自签名 TLS 例外仅适用于签名安装程序的已验证 loopback 端口，远端使用正常系统 TLS。WorkBuddy 加密认证不被解密。

官方 CLI 在使用凭据前验证签名；隔离目录为 0700，临时认证和持久元数据为 0600。不继承用户 hooks / MCP / 规则。账户元数据读取不生成回复；每次手动模型核验明确说明额度消耗，并禁用工具。子进程有超时、取消和目录清理。独立核验的预热与实际输出分开判断，冲突或缺失归属保持未确认。

番茄钟保存截止时间，每秒 tick 不写盘；暂停 / 停止取消 ticker。系统通知按截止时间安排，唤醒后修正剩余时间。菜单栏等宽字体包含秒。

OpenCode 的 step 费用优先于父 message，WorkBuddy 消耗积分按请求去重。本机费用不推算账户额度；余额、积分、已记录 USD 费用、手动价格估算分别标明。缺字段、溢出或非有限数保留未知。历史损坏不覆盖，CSV 对公式前缀转义。数据路径基于当前用户和标准安装位置，不内置开发者目录。

## 任务证据与工作区

应用由三个 Swift 模块组成：`ModelLensCore` 为只读检测和历史存储，`CodexModelLens` 为 SwiftUI / AppKit 界面，`ModelLensCLI` 提供可复核的命令行扫描。

界面使用系统侧边栏、原生工具栏、SF Symbols 和 `GlassEffectContainer` / `glassEffect`。玻璃材质用于导航、状态和操作，阅读主体保持简单、可选择文字。跟随系统浅色、深色和辅助功能材质设置。

每项模型证据保留类型、模型标识、可选原模型、任务 / 轮次关联、时间、来源文件及行号或数据库行 ID。SHA-256 ID 用于重复扫描去重，不是来源真实性签名。导入文件始终视为未经认证的外部证据。

逐轮保存请求模型，避免把任务最新设置反推到之前所有轮次。模型路由只附着到对应轮次，同一任务的下一轮不会继承上一轮服务端模型报告。任务设置不会覆盖轮次请求模型。一个轮次多次报告不同模型时保留所有证据，以时间排序展示最新报告。

本机没有可靠模型报告时，界面保留「暂无证据 / 实际模型未确认」。任何模型自述、提示文本、工具输出以及任意递归 JSON 里的 `model` 都不能提升为服务端证据。

1.1.0 将 `RequestRecord` 与模型交付证据分开：请求上下文、HTTP 状态、请求 ID、安全缓冲和可重试模型都保存为通信记录。结构化安全缓冲事件同样不属于 `isServerClaim`，不会影响 `reportedModel` 或模型差异判断。传输解析限于已知模块、明确日志前缀和 Responses 路径，响应头采用字段白名单；不复制完整头、Cookie、URL 查询字符串或响应正文。

请求统计同时展示记录数、按 ID 去重的请求数和缺少 ID 的记录数。诊断支持 UTC 日期范围及按模型／日期／任务分组；任务分组以 ID 为键，避免同名任务被合并。增量数据库读取以行 ID 为游标，文件替换或 ID 回退时重新检查；历史以来源、定位、时间、进程和请求 ID 组成的稳定 ID 去重。当前数据库覆盖范围和已归档证据范围分别保留。

三栏中间的容器始终填满可用高度；标题区域保持自身高度，内容区占据余下空间。空状态只在内容区居中，标题、搜索和底部状态的位置不随记录数变化。

历史保存采用原子 JSON；源文件消失或扫描失败不会丢弃旧证据，旧的运行中状态会降为待确认。损坏或未来版本历史文件不会自动覆盖。存储和导出错误必须显示。

本机保护检查使用文件大小、修改时间和符号链接目标的开发前后对比，不能称为内容哈希审计。验证结果位于 `Documentation/protected-files-after.json`。
